# Referências de terceiros do registro

Este registro descreve interfaces públicas e aponta para fontes fixadas. Não inclui corpos de stocks/implementações, headers completos, servidor/cliente SA-MP, assets GTA ou binários de plugins. Download de pesquisa permanece em `/build/`, ignorado pelo Git; não integra build/licenciamento do produto automaticamente. Nomes, assinaturas e expressões declaradas são atribuídos pelos links/linhas do catálogo e por `sources.lock.json`.

| Referência | Aviso observado | Uso neste trabalho / pendência |
|---|---|---|
| `pawn-lang/samp-stdlib`, R2 e DL | Cabeçalhos atribuem copyright 2005–2017 ao SA-MP Team; snapshots não possuem arquivo de licença de redistribuição identificado | Inventário de interfaces de mirror público, sem autenticação contra pacote original e sem incorporar headers/implementações. Resolver proveniência/licença antes de distribuir includes derivados ou dependências de release. |
| `openmultiplayer/omp-stdlib` | [MPL-2.0 / license.md](https://github.com/openmultiplayer/omp-stdlib/blob/46a5d1d7ac8985e4104f745c462a247a0c2eb6a0/license.md), avisos por arquivo | Fontes oficiais de referência. Não importar corpos de stocks ao código GrandMP. Se forem incorporados no futuro, preservar avisos e cumprir a licença correspondente. |
| Arquivos Pawn runtime dentro de `omp-stdlib` | `core.inc`, `string.inc`, `file.inc`, etc. mantêm avisos dos autores originais (ITB CompuPhase/Artran/etc.), alguns apenas “provided as is” | Não atribuir MPL indiscriminadamente a todo arquivo. Os bytes e avisos exatos estão fixados; escolher/verificar distribuição da VM/compiler/stdlib em S1 antes de integrar. |
| `openmultiplayer/web` | README identifica documentação de SA-MP e open.mp; licença raiz não identificada no conjunto lido | Resumos curtos de referência, URLs fixadas por página, sem copiar exemplos/corpus de docs para o produto. Semântica pode refletir comportamento open.mp distinto do clássico; revisão individual obrigatória. |
| `samp-incognito/samp-streamer-plugin/streamer.inc` | Header declara copyright Incognito e [Apache-2.0](https://github.com/samp-incognito/samp-streamer-plugin/blob/49d48e515b9a095f016fb6a208a2cd94c42acda5/streamer.inc#L1) | Catálogo distingue este plugin das natives do servidor. Nenhum binário/implementação incorporado, nenhuma alegação de compatibilidade ABI. |
| Wiki Streamer | Histórico Git próprio; licença específica não identificada nas páginas lidas | Referências a descrições/analogias, fixadas por commit separado. Não considerar documento mais antigo como confirmação automática de comportamento da versão do include. |

Este levantamento registra fatos observados e pendências de integração, sem declarar que disponibilidade pública concede licença para redistribuir código ou assets. A tarefa futura de VM, includes distribuídos ou plugin depende de avaliação explícita de versão/licença/atribuição. O registro atual não escolhe licença geral do GrandMP nem adiciona dependência de runtime.
